# Config to load on startup

All files under this directory will be loaded on startup.

`options.lua`, `keymaps.lua` and `autocmds.lua` are loaded by LazyVim after [LazyVim's](https://github.com/LazyVim/LazyVim/tree/main/lua/lazyvim/config) and [KoalaVim's](https://github.com/KoalaVim/KoalaVim/tree/master/lua/KoalaVim/config) config. Every other file is loaded by KoalaVim right after your keymaps.
